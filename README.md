# SAP Module Simulator

Desktop application untuk simulasi SAP GUI dengan modul lengkap.

## Module Progress

### Priority 1
- [ ] MM - Materials Management
- [ ] HCM - Human Capital Management

### Priority 2
- [ ] FI - Finance
- [ ] SD - Sales & Distribution
- [ ] CO - Controlling
- [ ] PP - Production Planning
- [ ] PM - Plant Maintenance
- [ ] EWM - Extended Warehouse Management

## Tech Stack
- PyQt5 (Desktop GUI)
- SQLite (Data storage)
- Python 3.12

## Installation
```bash
pip install PyQt5 openpyxl
python main.py
```

## Data Source
Excel files dari `~/Downloads/SAP MODUL/`
